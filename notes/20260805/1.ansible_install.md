# Install Ansible

## 1.Install EPEL (Extra Packages for Enterprise Linux) 
```bash
sudo dnf install -y epel-release 
```

## 2.Install ansible-core
```bash
sudo dnf install ansible-core
...

## 3.Check Version
```bash
ansible --version
```

### 3.Output
```text
ansible [core 2.16.19]
Python 3.12

> **Note**
> `Python 3.12` 表示 Ansible 是使用 Python 3.12 執行，並不是執行了 Python 指令。

...
```
## 4.List enabled Repositories
```bash
dnf repolist
```

> **Note**
- **`bash`**：表示這是一段 **Shell 指令**，可以在 Terminal 執行。
- **`text`**：表示這是 **指令執行後的輸出結果**，僅供閱讀，不能直接執行。
- **`epel-release`**：安裝 EPEL（Extra Packages for Enterprise Linux）Repository。
- **`ansible-core`**：Ansible 的核心套件。
