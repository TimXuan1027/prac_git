## Install Git & Push.command

## 1.Install Git
```bash
sudo dnf install -y git
git --version
```
## 2.Configure Git
```bash
git config --global user.name "TimXuan1027"
git config --global user.email "charles19911027@gmail.com"
git config --list
> **Note**
> 設定Git使用者與Email
```
## 3.Generat SSH Key
```bash
ssh-keygen -t ed25519 -C "charles19911027@gmail.com"
cat ~/.ssh/id_ed25519.pub
> **Note**
> 建在/home/tim 
> 用於GitHub SSH 驗證
> 顯示SSH公鑰，加入Git
> Github/ 右上角Settings/ SSH and GPG Keys/ New SSH Key/ 
```
## 4. Clone Repostory
```bash
git clone https://git.com/TimXuan1027/prac_git.git
cp -r ~/notes
git status
```
## 5. Add File
```bash
git add notes/ #暫存區
git commit -m "[Learning_Linux]"
git remote set-url origin git@github.com:TimXuan1027/prac_git.git #HTTPS改為SSH
```
## 6. Test SSH Connetction
```bash
ssh -T git@github.com
```
## 7. Push origin master
```bash
git push origin master
```
## 8. Pull
```bash
git pull --rebase origin master
```
